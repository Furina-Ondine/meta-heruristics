# ADR-0005: 候选、目标值与约束

## 状态

状态：Accepted

## 背景

首版需要稳定、可验证的连续单目标语义，同时为后续目标值和解表示扩展保留边界。

## 决策

- 候选位置使用连续 `double` 向量；每个变量可有上下界。
- 目标值使用标量 `double`，优化方向显式支持最小化和最大化。
- 候选比较遵循可行性优先：可行解优于不可行解；两个不可行解按归一化加权总违背量较小者优先。
- 等式约束使用显式绝对容差和相对容差判定；不等式约束按其方向判定违背量。
- 约束判定、候选比较和候选修复保持独立；修复是可选策略，不改变比较语义。

## 替代方案

- 首版直接泛化候选和目标值：扩展面更大，但会把尚未验证的抽象带入热路径。
- 仅比较原始违背量：不同量纲的约束无法公平比较。
- 将修复内置于约束判定：职责耦合，难以替换策略和验证行为。

## 后果

首版语义简单、可测试，约束比较不依赖具体修复算法；引入泛型目标、多目标或其他表示时须按路线图补充决策和契约。

## 重新评估条件

当泛型目标值、其他候选表示或新的约束类型进入实现路线图时，通过新 ADR 重新评估。
