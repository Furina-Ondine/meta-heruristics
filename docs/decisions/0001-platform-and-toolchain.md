# ADR-0001: 平台与工具链

## 状态

状态：Accepted

## 背景

项目需要统一、现代且可复现的 .NET 开发基线，同时保持运行时包跨平台，避免早期维护多套目标框架和工具配置。

## 决策

- 使用 .NET 10 SDK，所有项目以 `net10.0` 为目标框架，采用该 SDK 默认的稳定 C# 版本。
- 使用 `.slnx`、集中包版本管理和仓库级构建配置。
- 测试采用 xUnit v3 与 Microsoft Testing Platform；性能测量采用 BenchmarkDotNet。
- 运行时项目保持平台无关，不依赖仅限特定操作系统的 API。

## 替代方案

- 旧版 LTS：生态成熟，但会放弃当前 SDK 和运行时能力。
- 同时面向多个目标框架：扩大兼容范围，但首版会增加 API、测试和发布成本。
- 额外引入 StyleCop 等风格工具：暂由 `.editorconfig` 和编译器分析覆盖，出现真实缺口后再评估。

## 后果

开发、测试和基准使用一致工具链，配置较简单；使用方需要兼容 .NET 10。跨平台承诺只覆盖运行时包，不限制开发辅助工具。

## 重新评估条件

当 .NET 10 停止支持、目标用户确需其他框架，或现有分析工具无法维持一致性时，通过新 ADR 重新评估。
