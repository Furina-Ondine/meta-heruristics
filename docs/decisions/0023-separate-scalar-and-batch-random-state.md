# ADR-0023: 分离单值与批量随机状态

## 状态

Superseded

2026-09-08：由 [ADR-0024](0024-adaptive-vector-random-api.md) 替代。以下保留固定宽度方案历史。

2026-09-08，项目作者明确要求单个随机和批量随机分别维护 ulong 与 Vector512<ulong> 状态。替代 [ADR-0021](0021-run-private-simd-random-lanes.md)；仅确认此架构方向，完整行为见 2026-09-08 重新批准的 [SPEC-0010](../specs/SPEC-0010-simd-random-sampling/spec.md)。尚未实现。

## 背景

项目作者放弃 SPEC-0010 的旧共享 lane 方案及全部实施进度，要求从设计重新开始。旧决策禁止独立标量流，与当前指令冲突。

## 决策

- 一个 run 私有 RandomSource 分别持有单值和批量状态。xoshiro256++ 单值状态由四个 ulong 表达，批量状态由四个 Vector512<ulong> 表达。
- 单值和批量入口分别推进自己的状态，不能通过另一套状态补齐尾部或执行拒绝重试。
- 不新增公共随机源、PRNG、factory、后端配置或状态管理入口。保留 ADR-0021 的封闭 API、Core 所有权、显式 ulong seed、run/Group 生命周期、异常原子性与弱序列兼容边界。
- 保留通用向量 API、无硬件基础路径、禁止 ISA 专属 API 和 Core 源码生成器的边界。
- 初始化派生、分布路由、尾部消费和性能预算由重新审查的 Spec/Plan 完整规定；旧批准与证据不适用于新方案。

## 替代方案

- 全部入口共享 lane 和缓存：项目作者已明确放弃。
- 仅将旧状态容器改为 Vector512：仍不满足两套独立状态要求。
- 两个公共随机源或可配置后端：没有必要，保持现有公共入口。

## 后果

单值和批量消费互不推进，但状态体积及初始化成本增加。需要新隔离测试和性能证据；不能把旧实现性能或统计结果当作新方案验收。

## 重新评估条件

更换 PRNG、改变两类状态隔离、公开子流或新增后端时重新设计并替代本记录。
