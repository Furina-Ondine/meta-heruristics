## 问题与动机

基于提交 `819a40c`：现有候选路径分别遍历速度公式、TensorPrimitives.Clamp 和 TensorPrimitives.Add；每个粒子只采样一对 cognitive/social 随机系数。现有 SIMD 不等于所有后续融合都会更快，需要独立对照。

## 目标

调查速度计算、限幅、位置更新的融合收益、初始化随机循环及整代 cognitive/social 系数预取；每个粒子的两个随机系数继续由全部维度共享，不得改为逐维独立系数。

## 非目标

不修改 Options、公共 API、种群布局、算法系数、比较策略或并发模型；不为追求 SIMD 改变随机变量的相关结构。

## 架构契合

历史 ADR-0016 要求 PSO 限幅和位置更新继续使用 TensorPrimitives。若采用融合私有内核，已通过联合规格批准修改该限制，见 ADR-0025；具体候选仍须通过 Plan 和性能门槛。优先直接使用 TensorPrimitives；没有适用直接操作或未通过门槛时再评估 Algorithms 私有融合内核。

## 信任与责任边界

## 功能需求

### FR-001：算法语义与 SIMD 边界

- 前置条件：成功 ResetForRun。
- 触发行为：生成候选。
- 预期结果：个人最优、全局最优、代际选择与 Repair/Evaluate 顺序保持；同抽样输入的速度限幅和位置公式必须与标量参考对照。
- 边界情况：覆盖短维度、各向量宽度尾部、特殊数值和退化参数；数值误差准则在 Plan 预先固定。
- 验收标准：同随机输入标量参考差分、回调记录和算法行为测试通过。

### FR-002：批量随机与状态隔离

- 前置条件：使用当前 run 的随机源。
- 触发行为：执行批准布局的批量采样。
- 预期结果：允许改造前后固定 seed 轨迹变化；同版本、同环境、seed 与执行设置重复一致。允许按 Plan 明确的采样布局跨用户回调预取，包括评估整代 cognitive/social 系数批量生成；每个粒子仍独占一对由全部维度共享的系数。Initializer、Repair、Evaluate 的实际调用顺序、次数，以及位置、personal/global best 的更新时点保持不变。
- 边界情况：Plan 必须明确批次范围、角色映射、采样入口与尾部消费。算法与策略若消费同一类随机状态，预取可以改变各自取得的样本，这属于已接受的轨迹变化；单值与批量状态仍遵循 SPEC-0010 的隔离规则。缓冲仅为 Optimizer 私有，跨 run 复用且无需清零或额外重置；每次读取前完整写入本次有效区间，只读取本次已写入范围。不同 Group 的调度和拆分不影响结果。取消或异常后可保留数组内容，无需清理；原有异常传播、取消检查、不恢复已推进随机状态及异常后 Optimizer 不复用的规则保持。
- 验收标准：明确布局的样本角色与状态推进参考、策略分别使用单值/批量随机入口时的回调记录、重复、复用、Group 划分、并发隔离、取消和异常测试通过。不以与旧布局样本逐值一致作为要求。

## 非功能需求

### NFR-001：增量性能证据

- 测量方式：以现有 SIMD 生产实现为基线，测量内核和固定工作量完整 run；主要维度 32、128，诊断维度 1、2、7、8、15、16、24、25、31、33、64、65、127、129、1024。
- 可接受阈值：稳态候选无新增调用级分配；主要内核和端到端收益门槛在 Plan 固定，新增持久工作区单独计量。未通过候选删除。
- 证据类型：同机 BenchmarkDotNet、分配及反汇编；记录硬件支持、Runtime、基线和加速比；基准配置、完整命令、源 hash 和结果记录于 Verification。

## 职责与替代关系

- 新增：仅有实际消费者的私有计算路径或必要工作区。
- 替代/删除：被成功候选取代且不再承担回退职责的旧内核，不保留运行时切换配置。
- 保留：有独立回退用途的标量路径及测试参考。
- 唯一所属层：算法和工作区在 Algorithms，随机状态与分布在 Core。

## 成功标准

算法、状态与数值测试通过，每项保留优化有相对当前 SIMD 实现的增量收益证据；无收益时保留原实现并报告，不宣称优化成功。
