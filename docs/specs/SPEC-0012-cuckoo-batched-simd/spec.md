## 问题与动机

提交 `819a40c` 中 Lévy 候选逐维混合私有 NextGaussian、Pow、均匀采样与位置更新；遗弃候选也逐维抽样。Core 已有 StandardNormal.Fill，但 Cuckoo 仍保存私有正态实现和 spare。接入批量正态既影响随机轨迹，也涉及通用分布职责的清理。

## 目标

- 验证 Lévy 和遗弃候选批量采样、SIMD 算术的内核及完整 run 收益。
- 将通用标准正态生成统一到 Core，Cuckoo 只保留 Lévy 参数、缩放和公式。

## 非目标

- 不改变 Lévy 指数、epsilon、引导权重、遗弃数量、最差选择与最优更新规则。
- 不优化排序，不增加新分布 API、种群布局或公共后端。

## 架构契合

按 SPEC-0009 FR-008 独立批准批次布局。优先直接使用 TensorPrimitives；没有适用直接操作或未通过门槛时再评估 ADR-0025 涵盖的 Algorithms 私有融合内核。Core 保持通用随机与分布职责，Optimizer 独占必要缓冲。依赖 SPEC-0010 最终采样行为，但当前 StandardNormal.Fill 可作为独立算法候选基线。

## 功能需求

### FR-001：迁移正态采样

- 前置条件：接受新旧固定 seed 轨迹变化。
- 触发行为：生成 Lévy 候选的正态样本。
- 预期结果：通过 StandardNormal.Fill 获取独立标准正态样本，再执行原有缩放；删除 NextGaussian、spare 字段及其重置逻辑。
- 边界情况：Core 当前使用 1-u，而旧私有实现使用 Max(u, double.Epsilon)，迁移改变具体样本；不仅是方法重命名。奇数维度不得让不完整样本对或缓存泄漏到下次 run。
- 验收标准：分布检验、固定序列重复及复用测试通过；无重复通用正态实现残留。

### FR-002：保持候选与选择语义

- 前置条件：成功 ResetForRun。
- 触发行为：生成 Lévy 或遗弃候选。
- 预期结果：保留 Lévy 分母的 Abs/epsilon/Pow、缩放次序和 0.8/0.2 引导公式；保留遗弃差分与均匀扰动。允许候选内重排及跨候选预取正态、单位样本和索引对，具体布局在 Plan 固定。
- 边界情况：种群大小 P>1 时保持有序不同索引对的均匀分布，允许用 first=NextInt(0,P)、second=NextInt(0,P-1)、second>=first 时 second++ 替代相等索引重抽；P=1 时返回 (0,0) 且不采样索引；遗弃数量为 0 时不消费遗弃样本。特殊数值与窄向量尾部保持既有规则。索引对方案使用现有 NextInt，不恢复公共整数 Fill，也不在算法层复制通用无偏映射。
- 验收标准：同抽样输入下标量参考差分及分支行为测试通过；不得将向量超越函数误差默认为允许，Plan 必须列出误差准则。

### FR-003：回调与状态隔离

- 前置条件：独占 Optimizer 的顺序 run。
- 触发行为：初始化、候选替换与重复运行。
- 预期结果：允许按显式布局跨回调预取随机样本和索引；每个候选实际生成时读取当时的 best/population，不提前捕获会被前一候选更新的位置。保留实际 Initializer/Repair/Evaluate 次序、顺序替换、评估计数和取消行为；缓冲复用且每 run 重置。
- 边界情况：Plan 明确粒度、角色切片、标量/批量状态路由、尾部与未消费样本处置；同一 run 后续策略取得的随机值可能因批次重排和索引映射变化，这属于已批准的轨迹变化。
- 验收标准：回调事件、逐候选 best 更新、Group 隔离和生命周期测试通过。

## 非功能需求

### NFR-001：数值、分配与性能

- 测量方式：Lévy/遗弃内核和固定迭代完整 run，主要维度 32、128，诊断维度 1、2、7、8、15、16、31、33、127、129、1024；覆盖不同指数和遗弃率。
- 可接受阈值：稳态候选无新增调用级托管分配；保留候选须通过内核及主要端到端门槛；Plan 预先固定数值/统计容差和速度门槛，报告工作区成本。
- 证据类型：同机 BenchmarkDotNet、反汇编、分配和确定性数值测试；基准配置、完整命令、源 hash 和结果记录于 Verification。

## 职责与替代关系

- 新增：必要的 Cuckoo 私有随机缓冲与向量公式。
- 替代/删除：Cuckoo 私有正态生成与 spare；被取代的逐维计算。
- 保留：Cuckoo 的 Lévy 参数计算、索引抽样、选择逻辑和必要标量回退。
- 唯一所属层：标准正态在 Core，Lévy 步进和算法决策在 Algorithms。
