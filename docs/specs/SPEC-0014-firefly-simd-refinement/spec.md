## 问题与动机

基于提交 `819a40c`：现有距离和位置移动已由 SIMD 级联处理，但每次吸引移动仍逐维采样并缩放 randomWalk。现有 SIMD 不等于所有后续融合都会更快，需要独立对照。

## 目标

将每次实际吸引移动的随机游走接入 Fill，评估把随机缩放合入现有位置移动内核；复用已有 randomWalk 工作区。

## 非目标

不修改 Options、公共 API、种群布局、算法系数、比较策略或并发模型；不为追求 SIMD 改变随机变量的相关结构。

## 架构契合

沿用 ADR-0025 与 ADR-0019 的 Algorithms 私有级联边界，不新增公共 SIMD 后端。优先直接使用 TensorPrimitives；没有适用直接操作或未通过门槛时再评估 Algorithms 私有融合内核。

## 功能需求

### FR-001：算法语义与 SIMD 边界

- 前置条件：成功 ResetForRun。
- 触发行为：生成候选。
- 预期结果：保持吸引者顺序、以 source.Evaluation 决定吸引资格、以当前 target.Position 计算距离、每次移动后立即 Repair。允许在同一 source 候选内为后续实际移动预取随机样本，但不得提前计算距离或吸引力，也不得用原始 source.Position 替代前次 Repair 后的 target.Position。
- 边界情况：覆盖短维度、各向量宽度尾部、特殊数值和退化参数；数值误差准则在 Plan 预先固定。
- 验收标准：同随机输入标量参考差分、回调记录和算法行为测试通过。

### FR-002：批量随机与状态隔离

- 前置条件：使用当前 run 的随机源。
- 触发行为：执行批准布局的批量采样。
- 预期结果：允许改造前后固定 seed 轨迹变化；同版本、同环境、seed 与执行设置重复一致。随机样本可以按 Plan 明确布局跨越多个移动及其之间的 Repair 预取，但不得提前调用、重排、合并或省略用户 Initializer、Repair、Evaluate；实际移动、Repair 和 Evaluate 的时机保持不变。
- 边界情况：预取缓冲仅为 Optimizer 私有，可在顺序 run 间复用，不因 run 切换清零或额外重置；每次有效样本和索引先写满本次局部范围，再只读本次已写范围，容量余量的旧值不处理。不同 Group 的调度和拆分不影响结果；取消或异常沿用既有生命周期、异常传播和取消规则。
- 验收标准：重复、复用、Group 划分、并发隔离和取消测试通过。

## 非功能需求

### NFR-001：增量性能证据

- 测量方式：以现有 SIMD 生产实现为基线，测量内核和固定工作量完整 run；主要维度 32、128，诊断维度 1、2、7、8、15、16、24、25、31、33、64、65、127、129、1024。
- 可接受阈值：稳态候选无新增调用级分配；主要内核和端到端收益门槛在 Plan 固定，新增持久工作区单独计量。未通过候选删除。
- 证据类型：同机 BenchmarkDotNet、分配及反汇编；记录硬件支持、Runtime、基线和加速比；基准配置、完整命令、源 hash 和结果记录于 Verification。

## 职责与替代关系

- 新增：仅有实际消费者的私有计算路径或必要工作区。
- 替代/删除：被成功候选取代且不再承担回退职责的旧内核，不保留运行时切换配置。
- 保留：有独立回退用途的标量路径及测试参考。
- 唯一所属层：算法和工作区在 Algorithms，随机状态与分布在 Core。

## 成功标准

算法、状态与数值测试通过，每项保留优化有相对当前 SIMD 实现的增量收益证据；无收益时保留原实现并报告，不宣称优化成功。
